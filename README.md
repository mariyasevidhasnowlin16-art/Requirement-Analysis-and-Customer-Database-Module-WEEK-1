**E-Commerce Order Management Database System**

**Week 1 – Customer Database Module**

**Project Description**
This project focuses on designing and managing a Customer Database for an E-Commerce Order Management System using MySQL.

**Objectives**
Analyze e-commerce business requirements.
Design the Customer table.
Create the database with constraints.
Insert customer records.
Perform CRUD operations.

**Technologies Used**
Database: MySQL
Tool: MySQL Workbench

**Customer Table**
The Customer table stores the following details:

Customer_ID
Customer_Name
Email
Phone
Address
City
Registration_Date
Constraints Used
PRIMARY KEY – Customer_ID
NOT NULL – Required fields
UNIQUE – Email and Phone

**CRUD Operations**
Create – Create database and Customer table.
Read – Display customer records.
Update – Modify customer information.
Delete – Remove customer records.

**Conclusion**
The Customer Database was successfully designed and implemented using MySQL Workbench. It provides an organized way to store 
and manage customer information and supports basic CRUD operations efficiently.
